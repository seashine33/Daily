# 误码率测试
* 测试说明
  * 程序中统计了接收数据率，即接收成功的帧数/运行秒数
  * 由于一帧由4字节组成，数据缓冲区头字节非帧头，会将该字节丢弃，count_resolve_err 加一
  * 帧头无误，CRC校验未过，count_crc_err 加一
  * 本误码率测试只算 count_crc_err
