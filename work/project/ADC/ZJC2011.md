# ZJC2011
## 模式选择
* 繁忙模式会在数字位前强制增加一个繁忙位，变成每次传输17位，这是不想要的
* 先选择三线无繁忙模式实现
## 硬件使用
* 定时器
  * 定时器1：用于产生160K频率的中断，用于ADC采样
  * 定时器2：用于微秒延时，延时完成后有更新中断
  * 定时器6：HAL库Tick
* SPI
  * SPI1：ADC
  * SPI3：位置编码器

  * SDO(PA6): MISO
