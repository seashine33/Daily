# 三国杀规则
![alt text](image-3.png)
## 卡牌类型
* 身份牌
  * 主公：杀掉所有反贼
  * 忠臣：同主公胜利条件相同
  * 反贼：杀掉主公
  * 内奸：场上只有主公和内奸，干掉主公
* 血条牌![体力牌](image-2.png)
* 武将牌![武将牌](image-1.png)
* 基础牌
  * 杀
  * 闪
  * 桃
* 锦囊牌
  * 顺手牵羊：指定一名与你距离为1及以下的玩家的手牌中，抽取一张加入自己的手牌
  * 过河拆桥：指定一名任意玩家，从其手牌选一张牌丢弃
  * 乐不思蜀：判定牌的花色为红色，则跳过该回合的出牌阶段
  * 兵粮寸断：判定牌的花色为黑色，则跳过该回合的抽牌阶段
  * 南蛮入侵：全场出杀
  * 万箭齐发：全场出闪
  * 无懈可击：无效锦囊牌效果一次
  * 无中生有：抽两张牌
  * 闪电：
* 装备牌
## 其他游戏机制
* 游戏流程
  * 游戏开始，从主公开始抽牌，每个人抽四张作为起始手牌
  * 从主公开始第一个回合，每个玩家每回合开始时，先进入判定阶段，再进入抽牌阶段，抽两张牌

    * 结束阶段
